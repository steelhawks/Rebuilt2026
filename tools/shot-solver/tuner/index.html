        How to run & use
        
    
          
  1. Serve the site over HTTP (an HTTPS page can't open a plaintext NT4 socket). From tools/shot-solver:
            
    python3 -m http.server 8080
    
            then open http://localhost:8080/tuner/.
    2. 
          
  2. Tether to the robot (USB / radio). For sim, just leave the host as localhost.
    3. 
          
  3. Connect — type the robot host and hit Connect; the dot turns green.
    4. 
          
  4. Enable the gate — check Accept pushes (sets /GeneratedLUTTuner/Enabled). Make sure useLUT reads ON, or the table won't be used when shooting.
    5. 
          
  5. Tune & push — adjust the solver sliders on the left, then Generate + Push. The confirm box turns green when the robot's echoed hash matches (it's running your exact table).
    6. 
          
  6. Drive & verify — drive and shoot normally; the robot uses the pushed table live. Use the align helper to park at a test distance. Nudge a slider, push again, repeat.
    7. 
          
  7. Revert restores the baked LUT. The pushed table is RAM-only — a reboot also restores it, so just re-push. When happy, copy the Java (left panel) into loadLUTSolved to make it permanent.
